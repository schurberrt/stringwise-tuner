# Stringwise Tuner v3

Ein moderner, responsiver Gitarren-Tuner als Progressive Web App (PWA).

## Features
- **7 Tuning Presets:** Standard, Drop D, DADGAD, Open G, Half Step Down, Open D, C Standard.
- **Auto & Manueller Modus:** Saiten werden automatisch erkannt oder können per Klick fixiert werden.
- **Präzise Erkennung:** Nutzt Web Audio API und einen optimierten Autokorrelations-Algorithmus zur Frequenzberechnung.
- **Sicherheits-Bypass:** Start-Overlay stellt sicher, dass die App die Mikrofon-Restriktionen moderner Browser einhält.

## GitHub Pages Deployment
1. Entpacke dieses ZIP-Archiv.
2. Lade alle enthaltenen Dateien in ein neues, öffentliches GitHub-Repository hoch.
3. Aktiviere **GitHub Pages** unter `Settings -> Pages` auf dem `main` Branch.
